# 第2章「前の移住者」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 第1章の最後からそのまま第2章（夕方→夜、帰ってきた男、遺品3つ、スマホ通知、一斉停電、自分の窓の写真）を最後まで遊べるようにし、Windows 版で渡す。

**Architecture:** 既存の `game/`（Godot 4.3）に足す。進行（`ChapterFlow`）、記録（`GameState`）、通知・遺品・聞く信号・つきまとい・停電・写真は、シーンから独立して試せる小さな部品として作る。東地区の組み立ては `EastDistrict`、第2章の人物・調べる物・演出のつなぎ込みは `Chapter2` に置き、`slice_main.gd` には呼び出しだけを足す。

**Tech Stack:** Godot 4.3（GDScript）、in-repo minitest（`game/run_tests.sh`）、Blender（pip の `bpy`）、numpy＋ffmpeg（効果音）

**Spec:** `docs/superpowers/specs/2026-10-28-chapter2-design.md`（親：`docs/superpowers/specs/2026-10-26-sos-horror-game-design.md`）

## Global Constraints

- 画面に出る文字はすべて `tr()` 経由。翻訳表 `game/i18n/strings.csv`（列 `keys,ja,en`）に日本語と英語を足す。コードに文言を直接書かない。
- 信号・会話・通知・遺品・演出のきっかけはデータ（JSON）で持つ。
- 追跡なし。驚かせる演出は第2章で2回（`ch2_blackout`、`ch2_window_photo`）。
- 遺品は全体で5個。第2章は `watch`、`letter`、`nametag` の3個。
- 第2章の始めと「その夜」で自動セーブ。セーブの版（`SaveSystemNode.VERSION`）は 1 のまま、足したフィールドは無ければ既定値で読む。
- テストは `cd game && ./run_tests.sh [filter]`。SCRIPT ERROR が1つでも出たら失敗。
- 帰ってきた男は危害を加えない。屋内に入らない。プレイヤーの通り道をふさがない。
- 既存の序章・第1章の遊び方とテストを壊さない（`slice_end` を前提にしたテストは第2章に合わせて直す）。

## Review Focus

1. **v3 のセーブから「つづきから」** — v3 では index 9 が `slice_end`。第1章を終えた状態のセーブを読むと、第2章の始め（夕方の自宅、`chapter == 2`）から始まる。（Task 14 にテスト）
2. **会話中に通知・写真・停電の最後のひとことが来る** — 会話が閉じるまで待ってから出す。会話が上書きされたり、操作できなくなったりしない。（Task 13 にテスト）
3. **つきまとう男が道や戸口をふさぐ** — 男の当たり判定はプレイヤーの体と当たらない（調べるレイだけ当たる）。（Task 9 にテスト）
4. **停電中にプレイヤーが建物を出入りする・遠くへ行く** — 再点灯は最後まで進み、`restored` が必ず出る。手持ちの灯りは使える。（Task 8 にテスト）
5. **手帳やスマホの表示中に言語を切り替える** — 通知と遺品はIDで保存し、表示のたびに翻訳する。（Task 4 にテスト）
