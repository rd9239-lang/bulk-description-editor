## 2. 世界設定

### 2.1 舞台
- かつて炭鉱で栄え、閉山後にさびれた**架空の島**。実在の島・企業はモデルにしない。
- 連絡船は1日数便。最終便を逃すと朝まで出られない。
- 会社の自家発電所の名残で、島の電気（街灯を含む）は島の有力一族がまとめて操作できる。
- 炭鉱時代の名残で、古い島民は**信号の文化**を持つ（坑内の合図、戸を叩くリズムなど）。

### 2.2 犯罪（裏の真相）
1. 組織は身寄りの薄い男を探す。
2. **偽の妻**（本物の島の娘の身分を買った別人）がその男と結婚する。
3. 「島出身の妻の里帰り」として、島の**移住支援**を使って男を島へ連れてくる。
4. 男は消され、身分は別人に売られる。本人は船で運ばれ、強制労働させられる。
5. 死体が出ないため事件にならない。島では「夜逃げ」「出稼ぎ」で片づけられる。
6. 主人公は次の「商品」として選ばれていた。
7. **使えるうちは生かし、用済みになれば「海の事故」にする**。働けなくなった人は「漁船から転落して行方不明」として処理される。遺体が見つからなければすぐには死亡扱いにならないため、売られた身分はその間も別人が使い続けられる。用済みになった人の最期は描かず、ほのめかすだけにする。

### 2.2.1 殺さずに生かしておく理由（物語上の理屈）
- 死体が出ると事件になる。生きたまま遠い海の上にいれば、事件そのものが存在しない。
- 本人に利用価値がある。偽物に思い出や癖を教え込ませられ、強制労働で稼がせられる。
- 本人は身分を奪われているので、自分が誰かを証明できない。逃げ出しても、書類の上ではすでに別人が「本人」として暮らしている。
- 用済みになるまでの時間制限があるため、「早く助けないと、あの人たちも消される」という焦りが主人公とプレイヤーに生まれる。

### 2.3 二つのSOS（物語の核）
プレイヤーが物語の中で知る構図。作る側だけが知る補足は 4.4 を参照。

| | 本物のSOS | 罠のSOS |
|---|---|---|
| 送り手 | 廃坑に監禁された本物の娘 | 偽の妻（一族の指示） |
| 方法 | 坑内を通る古い電線への細工で、地上の街灯を点滅させる | 管理者として街灯・無線を直接操作する |
| 特徴 | 途切れがちで不正確。父から教わった独特の打ち癖がある | 正確できれいすぎる。癖がない |
| 目的 | 助けを求める | 主人公を夜の廃坑へひとりで誘い出す |

### 2.4 登場人物
| 人物 | 役割 |
|---|---|
| 主人公（夫） | よそ者。島出身の妻とともに移住してきた。身寄りが薄い |
| 妻（偽物） | 本物の島の娘の身分を買った別人。組織の一員。信号が読めないふりをしているが、実は完璧に読める |
| 本物の娘 | 廃坑に何年も監禁されている。偽物に思い出や島の話を教え込む「教育係」として生かされてきた |
| 妻の母・一族 | 組織の中心。島の電気と港を握る |
| 元炭鉱夫の老人 | 唯一の味方。指で机を叩く癖で警告を送ってくる |
| 島民 | 少数の実行役と、見て見ぬふりをする住人 |
| 前の移住者たち | すでに消えた男たち。遺品が証拠になる |
| 帰ってきた男 | 何年も船に乗せられた末に島へ戻された元移住者。寮で暮らす。自分の名前を思い出せず、番号で呼ばれると返事をする。机を叩く癖は船の上で覚えた作業の合図 |

## 3. 章構成

| 章 | 主な出来事 | 怖さ・遊び |
|---|---|---|
| 序章：帰郷 | 連絡船で到着。妻の実家にあいさつし、移住先の家へ。夜、窓の外の街灯が点滅している | 操作の練習。炭鉱資料館で坑内の信号とモールス信号の基本を知る（遊び方の説明を兼ねる） |
| 第1章：点滅 | 点滅がSOSだと気づく。近所の人ははぐらかし、妻は「古い街灯だから」と笑う。夜、ラジオが信号を拾う | 壊れかけの街灯の中から規則的な一本を見分ける。妻の小さな違和感 |
| 第2章：前の移住者 | 炭鉱住宅の廃墟や発電所跡を探索。移住支援で来た男たちが何人も消えていると知る。寮で「帰ってきた男」に出会う。老人から「打ち癖」の話を聞く | 探索・聞き込み・遺品集め。イヤホンからSOSが聞こえ始める。スマホに乗っ取りの通知が届き始める |
| 第3章：二つのSOS | きれいすぎる新しいSOSが届く。老人が姿を消す。発電所の古い通信記録で、本物のSOSの打ち癖が「妻の父が娘に教えたもの」と一致する。主人公名義の借金と引き継ぎ書を見つけ、章の終わりに**夕食の食卓**の場面 | 中盤の反転。二つの信号の聞き比べ。どちらのSOSを追うかで分岐 |
| 第4章：坑道 | 罠と知りながら夜の廃坑へ。追ってくる島民から隠れて進み、娘を見つける。イヤホンに妻から完璧な信号「オカエリ」が届く。入口の札掛けに自分の名前の札がある | 追跡・隠密。灯りを使うかどうかの駆け引き |
| 終章：脱出 | 娘を連れて港か灯台へ向かう | 追跡。エンディング分岐 |

### 3.1 偽の妻との対面
- **第3章の終わり（夕食の食卓）**：互いに相手が気づいていると分かりながら、普段どおりの会話を続ける。選択肢ごとに妻の微笑みが変わる。席を立つとき、それまで普通のノックしかしなかった妻が、食卓を**島のリズム**で叩く。
- **第4章（信号越し）**：妻は最後まで姿を見せない。坑道でイヤホンに完璧なモールス信号「オカエリ」が届き、罠のSOSを打っていたのが妻自身だったと分かる。

## 4. エンディング

### 4.1 分岐の判定に使う記録
| 記録 | 決まる場面 |
|---|---|
| `told_wife` 妻にSOSのことを打ち明けたか | 第1・2章の会話の選択肢 |
| `followed_signal` 本物と罠のどちらのSOSを追ったか | 第3章 |
| `relics` 前の移住者の遺品の数（全5個） | 第2〜4章の探索 |
| `old_man_alive` 老人を救ったか | 第3章で、すぐに老人を探しに戻ったかどうか |
| `found_daughter` 坑道で娘を見つけたか（時間内） | 第4章 |

### 4.2 エンディング一覧（判定は上から順に評価する）
| No. | 名前 | 条件 | 内容 |
|---|---|---|---|
| ⑤ | 打ち明け話（早期バッド） | `told_wife` | 妻が微笑み「じゃあ、一緒に確かめに行こう」。暗転。物語の途中で終わる |
| ④ | 次の点滅（バッド） | `followed_signal = 罠` | 坑道で捕まる。数か月後、主人公が暗闇でSOSを打っている。地上では新しい移住者の夫婦が点滅に気づく |
| ③ | ひとりの帰還 | `found_daughter = false` | 主人公だけが連絡船で逃げる。遠ざかる島で街灯がまだSOSを打っている |
| ① | 真相（トゥルー） | 娘を発見 ＋ `relics = 5` ＋ `old_man_alive` | 老人の船で脱出。証拠が警察に届き、組織は摘発される。後日談へ |
| ② | 名前のない人（ノーマル） | 上記以外で娘を発見 | 娘を連れて脱出するが、書類上「娘本人」はすでに島で暮らしている。助け出した本人のほうが偽物扱いされる |

### 4.3 トゥルーエンドの後日談
1. **島を出る船の上**：老人が手すりを指で叩く。読み解くと「ツギハ」。
2. **数か月後、都会の部屋**：夜、ラジオの雑音にかすかなSOSが混じる。打ち癖は、助け出した娘のものと違う。
3. **戸を叩く音**：同じ夜、玄関が叩かれる。「私です」と娘の声。ノックは島のリズムではない。
4. ドアノブに手をかけたところで暗転し、エンドロールへ。

### 4.4 作る側だけが知る「裏の答え」（ゲーム内では明かさない）
- 廃坑には二人の女性が監禁されていた。**本物の娘（A）**と、次の偽物として仕込まれていた**別の女性（B）**。
- AはBに自分の打ち癖を教えていた。どちらかが外に出られたときの命綱にするためだった。
- 第3〜4章でプレイヤーが追ったSOSは、手前の部屋にいたBのもの。主人公が助け出したのはBで、Bは生き延びるために「娘」として振る舞っている。島民ではないので、ノックは普通。
- Aは坑道のさらに奥、封鎖された区画に残っていて、警察の捜索でも見つからなかった。後日談のラジオのSOSはAのもの。
- **注意深いプレイヤーへのご褒美**：第1章で最初に見たSOS（A）と第3章のSOS（B）は、打ち癖がわずかに違う。後日談のラジオのSOSは第1章と同じ打ち癖にする。
- 老人の「ツギハ」は、まだ奥に人がいることを知っていた老人の警告。

## 5. 身分の乗っ取りと強制労働の怖さ

章が進むほど、怖さが「他人の話」から「自分の話」へ近づくように配置する。

| 章 | 要素 | 内容 |
|---|---|---|
| 第2章 | **帰ってきた男** | 寮で出会う元移住者。名前を思い出せず、番号で呼ばれると返事をする。捕まった後の姿をプレイヤーに想像させる。悪意ではなく壊れた人として描く |
| 第2章〜 | **今まさに乗っ取られていく** | 主人公のスマホに通知が届き始め、章ごとに増える。例：銀行「住所変更を受け付けました」→ 書いた覚えのないSNS投稿「島の暮らし、最高です」→ 母「さっき電話くれてありがとう、元気そうでよかった」 |
| 第3章 | **主人公名義の借金** | 移住支援の「住宅改修ローン」が主人公の名前で組まれていた。署名したのは妻。強制労働は法的には「借金の返済」という形になる |
| 第3章 | **引き継ぎ書** | 妻の日記だと思って開いたノートが、主人公の身分の買い手に渡す引き継ぎ書だった。主人公の癖の観察メモ（「コーヒーに砂糖二つ」「寝る前に右手で首をかく」「母への電話は日曜の夜、5分ほど」）。夕食の食卓の場面の直前に見つける |
| 第4章 | **入坑札** | 廃坑の入口に、誰が坑内にいるかを示す札掛けが残っている。「入坑中」の列に消えた男たちの札が今も掛かり、その端に**主人公の名前の札がもう掛かっている**（炭鉱の札管理は時代や地域で違うため、資料を確認して描写を決める） |

- スマホの通知は、受け取った通知の一覧として手帳から見返せるようにする。
- 引き継ぎ書に書かれた主人公の癖は、序章〜第2章で主人公が実際にとる行動（コーヒーを入れる、母に電話する場面など）と一致させ、読んだ瞬間に「見られていた」と分かるようにする。

## 7. 遊び方

### 7.1 基本の流れ
昼に島を歩いて住人と話し、場所を調べる → 夜に信号を観察して読み解く → 読み解いた内容で次の場所が開く。章が進むほど夜が長く、危険になる。

### 7.2 信号
| 手段 | 操作 |
|---|---|
| 街灯 | 窓辺や路上で見て、点滅を記録する |
| ラジオ | つまみを回して周波数を合わせる |
| イヤホン | 終盤、耳元に直接届く |
| ノック・指の叩き | 住人の癖として、さりげなく聞こえる |

- 記録した信号は**信号手帳**に波形で残り、二つを並べて聞き比べられる。
- **解読方式（決定：C）**：物語を進める信号は手帳が自動で文字にする。打ち癖の違いや老人の指の叩きなど隠れた信号は自動で訳さず、気づいた人だけが自力で解読する。

### 7.3 怖さの出し方（決定：B＋D）
- 戦闘なし。
- 追われる場面は**第4章と終章のみ**。見つかると捕まる演出が入り、直前からやり直し。手持ちの灯りを点けると周りが見えるが、見つかりやすくなる。
- 第1〜3章は、決められたタイミングで起きる驚かせる演出を**各章1〜2回**だけ入れる（例：街灯の下に人影が立ち、点滅に合わせて消えたり現れたりする）。

### 7.4 セーブ
- 章の区切りと主要な場所への出入りで自動セーブ。
- クリア後は章選択でやり直せる（分岐回収用）。

## 8. 技術構成

### 8.1 使うもの
- ゲームエンジン：**Godot 4**（GDScript）
- 3D素材：**Blender**（Python スクリプトで生成）＋ AI 生成の小物 ＋ 購入素材の人物
- 取り込み形式：glTF

### 8.2 ゲーム本体の部品
| 部品 | 役割 | 依存先 |
|---|---|---|
| `Player` | 一人称移動、しゃがみ、手持ちの灯り | — |
| `Interaction` | 調べる、拾う、扉を開ける | Player |
| `Dialogue` | 選択肢つき会話。選択結果を `GameState` に書く | GameState |
| `SignalCore` | モールスの符号化・復号、打ち癖からの時刻列の生成 | — |
| `SignalSource` | 街灯、ラジオ、イヤホン、ノックの共通の発信元。`SignalCore` の時刻列で光・音を鳴らす | SignalCore |
| `Notebook` | 信号の記録、波形表示、聞き比べ、自動変換（隠れた信号は除外） | SignalCore, GameState |
| `GameState` | 進行の記録（`told_wife`、`relics` など）と、エンディング判定 | — |
| `SaveSystem` | 自動セーブ、読み込み、章選択 | GameState |
| `Pursuer` | 巡回、視界、灯りへの反応。第4章・終章のみ | Player |
| `ScareDirector` | 決められた場所・タイミングの演出 | GameState |
| `AudioDirector` | 立体音響、ラジオの雑音、イヤホン越しの音 | — |
| `PhoneFeed` | 主人公のスマホへの通知（乗っ取りの進行）。進行の記録に応じて届き、手帳から見返せる | GameState, Notebook |

### 8.3 データの持ち方
- 信号は**データ**として定義する（文言、打ち癖のパラメータ、自動変換するかどうか）。打ち癖は、点の長さ、線と点の比、文字間・語間の間、揺らぎの大きさ、の数値で表す。
- 本物のSOS（A・B）と罠のSOSの違いは、このパラメータの差で作る。
- 会話、エンディング条件、演出のトリガーもデータで持ち、コードを変えずに調整できるようにする。

### 8.4 3D素材の作り方
- 電柱、街灯、炭鉱住宅、塀、ガードレールなど：Blender の Python スクリプトで部品化し、組み合わせて使う。
- 小物：AI で生成し、Blender で軽量化と質感の調整をする。Steam では AI 生成素材の使用を申告する。
- 人物：購入素材。
- 主役の見た目（街灯、島の景観）は AI 生成を使わない。

### 8.5 多言語対応（決定：日本語＋英語）
- 最初から Godot の翻訳機能（翻訳表）を使い、画面の文字をコードに直接書かない。
- モールス信号は英語のアルファベットでも同じく成り立つ。和文モールス（カナ用の符号）は日本語版の隠し要素にする。

## 9. テスト
- 自動テスト（Godot 用のテストツールを使う）の対象：
  - モールスの符号化・復号
  - 打ち癖からの時刻列の生成（同じパラメータなら同じ結果、A・B・罠の差が閾値以上あること）
  - エンディング判定（4.2 の全条件の組み合わせ）
  - セーブと読み込み（保存した記録が完全に戻ること）
- 手動確認：各章の通しプレイ、全エンディングの到達確認、日本語・英語の表示確認。

## 10. 作る順番
1. **縦切り試作（序章＋第1章）**：島の一部、家、街灯の点滅、ラジオ、信号手帳、会話、セーブ。「点滅に気づく瞬間が怖いか」をここで確かめる。
2. 第2〜3章：探索範囲の拡大、遺品、老人、聞き比べ、食卓の場面。
3. 第4章・終章：坑道、追跡する島民、エンディング5種、後日談。
4. 仕上げ：英語翻訳、実績、ストアページ素材（Blender で予告編）、テストプレイ。

## 11. 表現上の注意
- 人身売買・強制労働は性的な描写に踏み込まず、「人が消えていく怖さ」に絞る。
- 炭鉱の歴史や実在の拉致事件は直接モデルにしない。架空の島・架空の会社にする。
- Steam の成人向けコンテンツの申告と年齢設定は、内容が固まった段階で確認する。
