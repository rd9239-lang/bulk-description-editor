# 設計書：第2章「前の移住者」

- 日付：2026-10-28
- 親の設計書：`docs/superpowers/specs/2026-10-26-sos-horror-game-design.md`（以下「全体設計」）
- 前提：序章＋第1章の縦切り試作（`game/`）と、試遊の感想を反映した v3 まで完成済み

## 1. 目的と成功の条件

第1章の「点滅に気づく怖さ」から、怖さを「消えた他人の話」へ広げ、最後に「自分も見られている」へ近づける。

成功の条件：
- 第1章の最後（ラジオの信号を記録）から、そのまま第2章に入って最後まで遊べる（約20〜30分）。
- 帰ってきた男が「悪意ではなく壊れた人」として伝わり、つきまとわれる居心地の悪さがある。
- 驚かせる演出は2回（一斉停電、自分の窓の写真）。
- 第3章の伏線（コーヒーの砂糖、母への電話、坑内線、打ち癖）が置かれている。
- 「つづきから」で第2章の始めから再開できる。

## 2. 決定事項（相談で決めたこと）

| 項目 | 決定 |
|---|---|
| 範囲 | 第2章だけ作って遊んでもらう |
| 帰ってきた男 | 悪意ではなく壊れた人。会話中心＋少しつきまとう不気味さ |
| 驚かせる演出 | 一斉停電／自分の窓の写真（おまかせで決定） |
| 時間帯 | 前半は**曇りの夕方**、後半は夜 |
| 舞台 | 今の通りを東へ延ばす（地続き）。第1章までは工事柵で通行止め |

## 3. 物語の流れ

### 3.1 章の入り方
第1章の最後の目標（ラジオで信号を記録）が終わると、暗転して「第二章　前の移住者」のカードが出る。時間帯が夕方になり、主人公は自宅で目を覚ます。ここで自動セーブする。

### 3.2 目標の順番

|---|---|---|---|
| 1 | `ch2_phone` | 机のスマホを見る | スマホを調べる（通知①が届く） |
| 2 | `ch2_coffee` | 台所でコーヒーを入れる | やかんを調べる |
| 3 | `ch2_dead_lamp` | 消えたままの街灯を調べる | 根元を調べる（遺品①） |
| 4 | `ch2_old_man` | 港の老人に話を聞く | 会話の終わり（東の通行止めが開く） |
| 5 | `ch2_dorm` | 寮を訪ねる | 帰ってきた男との会話の終わり（つきまといが始まる） |
| 6 | `ch2_ruins` | 炭鉱住宅の廃墟を調べる | 掲示板と手紙（遺品②）の両方を調べる |

- 6 から 7 へ進むとき暗転し、「その夜」のカードとともに夜になる。プレイヤーはその場に残る（家まで歩いて帰る）。
- 遺品③（発電所のロッカー）は寄り道で、目標には入れない。

### 3.3 場面ごとの内容

**① 目覚めとスマホ（自宅・夕方）**
- 机のスマホが震えている。通知①「〇〇銀行：ご登録住所の変更を受け付けました」。
- 主人公「……手続きした覚えはない」。机に妻の書き置き「母のところへ行ってきます」。
- やかんを調べてコーヒーを入れる。主人公「砂糖は二つ」。（第3章の引き継ぎ書「コーヒーに砂糖二つ」の仕込み）

**② 消えたままの街灯（通り・x=44）**
- 第1章からずっと消えている1本の根元、側溝のふたのすき間に**遺品①「止まった腕時計」**。裏に名前の刻印（前の移住者のひとり）。

**③ 港の老人（港・桟橋の近くのベンチ）**
- 近づくと、老人が指でベンチを叩いている（隠れた信号 `oldman_nigero`「ニゲロ」。近くで聞き続けると手帳に記録でき、解読は自分でする）。
- 会話の要点：
  - 「移住支援で来た男は、あんたの前に4人おった。みんな出稼ぎに行ったことになっとる」
  - 「坑内の合図はな、音を聞けば誰が打ったか分かった。手の癖は消えん」（打ち癖の話）
  - 「寮に、帰ってきたのがおる。……あれに会えば分かる」
  - 「島の灯りは、いまも発電所の跡から切ったり点けたりできる」
- 会話が終わると、東の工事柵が外れている（通れるようになる）。

**④ 寮と帰ってきた男（寮の食堂・夕方）**
- 食堂の長机にひとりで座っている。机を「3回叩いて、2回止める」を繰り返す（船の作業の合図。信号としては記録しない）。
- 会話（選択肢つき・どれを選んでも先へ進む）：
  - 名前を聞く →「名前……」長い間。「……17番」。番号で呼ぶと「はい」と即答する。
  - どこから来たか聞く →「海です。ずっと、海」
  - 島の暮らしについて →「ここの暮らし、いいでしょう。奥さん、優しいでしょう。……おれのも、優しかった」
- 最後に「17番、作業に戻ります」と言って黙る。

**⑤ 炭鉱住宅の廃墟（長屋・夕方）**
- 長屋の入口に古い掲示板。「移住支援　ご入居の皆さま」の紙に4人の名前と入居日、その横にそれぞれ「転出」の判。
- 奥の一室（前の移住者の部屋）に**遺品②「出しそびれた母への手紙」**：「こっちの暮らしは順調です。妻もよくしてくれます。ただ、夜になると窓の外の街灯が、何か言っているように見えるのです」
- 主人公「……この人も、あの点滅を見ていた」

**つきまとい（④の会話のあと〜章の終わり）**
- 帰ってきた男が屋外で8〜10mほど離れてついてくる。
- プレイヤーが彼の方を見ている間は立ち止まり、こちらを向いて動かない。目を離すと、また歩いてくる。
- 家や建物の中には入らない。プレイヤーが屋内にいる間は、外で立って待つ。
- 近づいて話しかけると、断片的なひとことを返す（順番に）：「17番、作業に戻ります」「あなたは何番ですか」「奥さん、待ってますよ」「……網、重いですね」
- 危害は加えない。逃げたり隠れたりする必要はない（追跡は第4章から）。

**⑥ 母への電話（自宅・夜）**
- 暗転して「その夜」。家に帰り着くと、主人公が母に電話をかける（会話が自動で始まる）。短い会話（「元気でやってる」「日曜の夜はいつも電話くれるね」「5分だけね」）。
- （第3章の引き継ぎ書「母への電話は日曜の夜、5分ほど」の仕込み）

**⑦ 発電所跡（夜）**
- 建屋の奥の配電盤に、街灯の系統の札が並ぶ。そのうち1本に「坑内線」と書かれた古い線がつながっている。主人公「坑道の中から来ている線……？」（本物のSOSが坑内から来ている伏線）
- 古い線のそばに立つと、**イヤホンからノイズとSOS**が聞こえる（耳元・立体でない音）。聞き続けると記録 `sos_a_earphone`。
- 寄り道：ロッカーの作業着に**遺品③「名札」**。

**驚かせる演出① 一斉停電（発電所跡）**
1. `sos_a_earphone` を記録した直後、「ブツン」という音とともに島じゅうの灯り（街灯・室内灯・発電所の灯り）が消える。手持ちの灯り（F）だけは使える。
2. 3秒の静けさのあと、遠くの街灯から順に、こちらへ向かって「カチッ」という音とともに点き直る（約0.35秒おき）。
3. 最後に発電所の入口の灯りが点くと、その下に帰ってきた男が立っている。驚かせる音が鳴る。男「17番、戻りました」（会話は自動で出る）。
4. 以後、つきまといは続く。

**驚かせる演出② 自分の窓の写真（自宅・夜）**
1. 家に帰り、窓を調べる（第1章の「窓の外を見る」と同じ窓）。
2. スマホが震え、通知②「あなたの投稿に『いいね』がつきました」。そのまま投稿が開く。
3. 自分のアカウントの、覚えのない投稿「島の暮らし、最高です」。写真は**夜の路地（SOSの街灯の下）から撮ったこの家の窓**で、窓の中に人影が立っている。
4. 写真はゲーム内でその瞬間に撮る。プレイヤーが立っている位置に人影を置いて撮るので、写っているのは「いま窓辺にいる自分」。
5. 主人公「……これ、いま撮られてる」。窓の外を見ても、路地には誰もいない。
6. 「第二章　おわり」のカード。

## 4. 舞台

### 4.1 配置（x が東、z が北。今の通りは x=-1〜68）
| 場所 | おおよその位置 | 中身 |
|---|---|---|

| 道路の延長 | x=68〜125 | 地面・道路・街灯4本（ふつうの点灯2、ちらつき2）・電柱 |
| 老人のベンチ | (2, 0, -3.5) | 港の灯りのそば、海を向いて座る |
| 寮 | x=72〜84、北側（z=4〜14） | 2階建てのコンクリート造。1階の食堂だけ入れる |
| 炭鉱住宅の廃墟 | x=88〜110、南側（z=-6〜-16） | 長屋3棟。入口に掲示板。1室だけ入れる。屋根の一部が落ち、窓は板でふさがれている |
| 発電所跡 | x=114〜128、南側 | 煙突つきの建屋。中に配電盤とロッカー。入口に街灯1本 |
| 自宅（既存） | x=54〜60 | やかん、スマホ、書き置きを足す |

- 地面は東へ x=135 まで広げ、東端は見えない柵で止める。
- 新しい屋内（寮の食堂、長屋の一室、発電所の建屋）は既存と同じく屋内の範囲を置き、入ると外の音がこもる。

### 4.2 3D素材
Blender の Python スクリプト `tools/blender/build_east_district.py` で作り、`east_district.glb` に書き出す。部品の原点は底面の中心。
- 寮：2階建ての箱型、窓、入口のひさし、外階段。1階の食堂（長机・長いす）
- 長屋：既存の家の部品を流用しつつ、崩れた屋根・板でふさいだ窓・傾いた戸
- 発電所跡：建屋、煙突、配電盤（札が並ぶ板）、ロッカー、古い太い線
- 工事柵、ベンチ、やかん、スマホ、書き置き、掲示板
- 人物：老人と帰ってきた男は既存の人型（`Mannequin_F`）を服の色で区別する

質感は既存の素材表（`MaterialLibrary`）のコンクリート・トタン・木材・金属を使う。

## 5. 夕方の見た目

- `GraphicsSettings.build_environment(quality, time_of_day)` に時間帯 `&"dusk"` / `&"night"` を足す。
- 空のシェーダーに夕方用の色を足す：地平線は暗い橙、天頂は灰色がかった紺、星は出さない、西の低い位置に雲ごしの太陽のにじみ。
- 「Moon」の平行光は夕方には低い西日（暖色・弱め）、夜は今までどおりの月明かり。
- 霧は夜より薄く、明るさ（露出）は夜より少し上げる。
- 街灯は夕方から点いている（点滅する街灯もそのまま）。
- 時間帯は `GameState.flags["time_of_day"]` に保存し、読み込み時に戻す。

## 7. データ

- `data/dialogue/ch2.json`：第2章の会話（老人、帰ってきた男、つきまといのひとこと、母への電話、主人公のひとり言）
- `data/phone.json`：`[{id, trigger, sender_key, text_key, photo}]`。`photo: true` の通知は写真つき投稿として開く
- `data/relics.json`：`[{id, name_key, desc_key}]`（第2章は `watch`、`letter`、`nametag` の3つ。全体で5つ）
- `data/signals.json`：`sos_a_earphone` を追加（文言 SOS、打ち癖は本物の娘 `daughter_a`、自動で文字にする）
- `data/scares.json`：`ch2_blackout`、`ch2_window_photo` を追加
- 画面の文字はすべて `i18n/strings.csv` に日本語・英語で足す

## 8. セーブ

- 第2章の始め（夕方の自宅）と、「その夜」に切り替わったときに自動セーブする。
- `GameState` に `phone`（届いた通知のIDの並び）と `relics_found`（拾った遺品のID）を足し、保存と読み込みで完全に戻す。`relics` の数は `relics_found` の数と一致させる。
- 「つづきから」は、保存した目標に合わせてプレイヤーの位置と時間帯を戻す（第2章の始めなら夕方の自宅、夜の目標なら夜の自宅）。
- `east_open` が立っていれば工事柵を出さない。つきまといは `ch2_dorm` 以降なら再開する。

## 9. 音

既存の合成スクリプト（`tools/audio/generate_sounds.py`）に足す：
- `phone_vibrate`：机の上で震えるスマホ（低いうなりの断続）
- `finger_tap`：指で木を叩く軽い音（老人の信号の音）
- `earphone_static`：耳元のノイズ（イヤホンのSOSはこの上に信号音を重ねる。屋内でもこもらない）
- `power_down`：灯りが落ちる「ブツン」と、うなりが止まる音
- 再点灯の「カチッ」は既存の `lamp_click` を使う
- 夕方の環境音：虫の音を弱め、風と波を少し強める

## 10. テスト

自動テスト（既存の minitest）：
- 目標の順番：第1章の最後から第2章へ移り、各目標が順番どおりにしか進まない
- 記録がそろうと終わる目標（`ch2_ruins`）
- 遺品：拾うと数が増え、同じものは二度数えない。セーブと読み込みで戻る
- スマホ：きっかけで通知が届き、二度届かない。セーブと読み込みで戻る
- `AudibleSource`：範囲内で記録が進み、範囲外では進まない。ラジオは電源が入るまで聞こえない（既存テストを保つ）
- `Follower`：見られている間は動かない／見ていないと近づく／屋内には入らない／離れすぎると背後へ回る
- `PowerGrid`：消灯で全部消え、再点灯は遠い順で、最後に指定の灯りが点く
- `TimeOfDay`：夕方と夜で環境が切り替わり、保存した時間帯で戻る
- `PhotoCapture`：画像が1枚できる（大きさが正しい、真っ黒ではない）
- 通しのテスト：第2章の目標を順に完了して `ch2_end` まで到達し、スクリプトのエラーが出ない

手動確認：
- 画面写真（夕方の通り、寮、廃墟、発電所、停電中、写真の投稿）を撮って見た目を確かめる
- Windows 版を書き出し、Linux 版で起動確認をしてから渡す
