## 3. 物語の流れ

### 3.1 章の入り方
第2章の終わりのカード「第二章　おわり」のあと、暗転して「第三章　二つのSOS」のカードが出る。次の日の夕方、自宅で目を覚ます。自動セーブ。第2章の `ch2_end` は終わりの目標ではなくなり、カードのあとに自動で完了して第3章へ進む。

### 3.3 場面ごとの内容

**① 目覚めと通知③（自宅・夕方）**
- 机のスマホが震えている。通知③「母：今朝も電話くれてありがとう。声が少し違ったけど、風邪？」
- 主人公「……今朝？　電話なんてしていない」

**② 妻が帰ってきている（自宅）**
- 妻は台所にいる。炭鉱の唄を口ずさんでいるが、ラジオで流れていた節回しと少し違う（説明はしない）。
- 会話の要点：
  - 妻「おかえり。……ゆうべ、遅かったね」
  - 妻「最近、夜になると窓の外ばかり見てるね。何かあるの？」
  - 選択肢「街灯のことを話す」→ `told_wife = true`（既存の早期エンド⑤「打ち明け話」へ）
  - 選択肢「なんでもない」→ 妻「そう。……ならいいけど」

**③ 老人がいない（港）**
- ベンチに老人の姿がない。ベンチを調べると、座面に指でつけた細かい傷が並んでいる。
- 主人公「……誰かに連れて行かれた？　小屋のほうへ、何かを引きずった跡が続いている」
- 近所の老婆に聞くと「息子さんのところへ行ったよ。急にね」（任意の会話）。

**漁具小屋（寄り道・老人を救う）**
- 港の裏の漁具小屋。戸に外から閂がかかっている。
- **夜になる前に**閂を外すと、中に老人が座り込んでいる。
  - 老人「……すまん。来てくれると思っとった」
  - 話しながら指で床を叩く。2つ目の隠れた信号「MUSUME IKITERU」（ムスメ イキテル）。近くで聞き続けると記録でき、解読は自分でする。
  - 救出の記録 `flags["old_man_rescued"] = true`。
- **夜になってから**来ると、小屋は空。桟橋の端に老人の帽子だけが落ちている。主人公「……海の事故、か」。夜に入った時点で救出していなければ `old_man_alive = false`。

**④ 発電所の記録室**
- 発電所の建屋の奥に、仕切られた小部屋（記録室）を足す。机に古い通信記録の束とテープレコーダー。
- 通信記録：「合図係　○○（妻の父）　娘に打ち方を教える。練習の録音」。
- テープレコーダーを調べると再生が始まる。幼い娘が自分の名前「CHII」を打つ練習の音（打ち癖は本物の娘 `daughter_a`）。近くで聞き続けると `chii_tape` として記録される。

**⑤ 聞き比べ（手帳）**
- 手帳に新しく「聞き比べ」の画面を作る。上に練習テープの波形、下にほかの記録済みの信号を1つずつ並べて見比べる。
- 「この手と同じ打ち癖のものを選ぶ」
  - 打ち癖が本物の娘（`daughter_a`）の信号（第1章の街灯、ラジオ、第2章のイヤホン）を選ぶ → 正解。主人公「……同じ手だ。あのSOSを打っているのは、この子だ」
  - 罠の打ち癖（正確すぎる）を選ぶ → 「こんなにきれいな打ち方じゃない」
  - それ以外 → 「……違う気がする」
- 間違えても罰はなく、何度でも選び直せる。

**⑥ 借金の書類と遺品④（自宅）**
- 箪笥の奥に封筒。「住宅改修ローン　契約者：（主人公の名前）」。署名欄の字は妻の字。主人公「……書いた覚えはない」（強制労働が「借金の返済」になる伏線）。
- 同じ封筒の下に**遺品④「野々村の手帳」**：「妻の様子がおかしい。夜、誰かと電話で僕の話をしている」。

**⑦ きれいすぎる新しいSOS（夜・北の道）**
- 暗転して「その夜」。北の坑口へ続く道の街灯が、正確すぎるSOSを打っている（打ち癖 `trap`、揺らぎなし）。
- 見続けて `sos_trap` を記録した直後に**驚かせる演出①**：通り中の街灯が一斉に消え、全部の街灯がまったく同じリズムでSOSを1回だけ打つ。そのあと元に戻る。

**⑧ 通気坑のイヤホン（夜）**
- 炭鉱住宅の廃墟の裏に、格子でふさがれた通気坑の入口がある。そばに立つとイヤホンに粗いSOSが入る（打ち癖 `captive_b`。全体設計 4.4 のとおり、第1章のSOSとわずかに違う）。記録 `sos_b`。

**⑨ 追う信号を決める（手帳）**
- 手帳に「追う信号を決める」が出る。選べるのは `sos_trap`（北の街灯）と `sos_b`（通気坑のイヤホン）。
- `sos_b` → `followed_signal = &"real"`（第4章は通気坑から）。`sos_trap` → `followed_signal = &"trap"`（第4章は正面の坑口から）。
- 決めたあとは変えられない。

**⑩ 引き継ぎ書（自宅）**
- 居間に妻のノートが置いてある。日記だと思って開くと、主人公の身分の買い手に渡すための引き継ぎ書だった。
  - 「コーヒーに砂糖二つ」「母への電話は日曜の夜、五分ほど」「寝る前に右手で首をかく」
  - 最後の行：「引き渡し予定日：今月末」
- 主人公「……見られていた」

**⑪ 夕食の食卓（章の終わり）**
- 妻「遅かったね。ごはん、温め直すね」。食卓につくと、プレイヤーは座ったまま妻と向き合う（移動できない）。
- 3回のやり取り。どの選択肢でも先へ進み、妻の返しが変わる：
  1. 妻「今日はどこに行ってたの？」→「散歩」／「発電所の跡」
  2. 妻「お母さん、元気だった？」→「元気だったよ」／「……今朝、電話した？」
  3. 妻「ねえ。ここでの暮らし、気に入ってくれた？」→「うん」／「……君は、誰なんだ」
- 妻の返しは、選択肢に応じて「微笑みが少し深くなる」「微笑みが消える」などの地の文で表す。
- 席を立つとき、**驚かせる演出②**：これまで普通のノックしかしなかった妻が、食卓を**島のリズム**で叩く。主人公「……島の、叩き方だ」
- 暗転して「第三章　おわり」。

## 9. テスト

自動テスト：
- 目標の順番：`ch2_end` から第3章へ進み、各目標が順番どおり。夕方・夜の切り替わりとセーブ
- 老人の救出：夜の前に小屋を開けると救出、夜に入ると `old_man_alive = false`、救出済みなら夜でも true のまま
- 聞き比べ：`daughter_a` の信号は正解、罠は不正解、`captive_b` は不正解（違う気がする）
- 追う信号の選択：`sos_b` → `real`、`sos_trap` → `trap`、一度決めたら変わらない
- 街灯の一斉SOS：全街灯が同じタイミングで点き、終わると元の点き方に戻る
- 打ち明けると早期エンド⑤になる
- 通しのテスト：第3章の目標を順に完了して `ch3_end` まで到達し、スクリプトのエラーが出ない
- 「つづきから」：第3章の始め、夜の途中から戻れる

手動確認：画面写真（漁具小屋、記録室、聞き比べ、北の坑口、一斉SOS、通気坑、食卓）、Windows 版の書き出しと起動確認。
