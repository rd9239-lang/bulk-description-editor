対象拡張機能：概要欄 一括置換 for YouTube™ Studio（Bulk Description Editor）
最終更新日：2026年8月14日

English version below →

この拡張機能は、利用者のデータを外部に一切送信しません。 すべての処理は利用者のブラウザの中だけで完結します。開発者を含め、第三者がデータを受け取ることはありません。

1. アクセスする情報

この拡張機能は、利用者が明示的に操作を実行したときにのみ、 https://studio.youtube.com 上の以下の情報にアクセスします。

  • 利用者自身のチャンネルの動画一覧（動画IDとタイトル）
  • 利用者自身の動画のタイトルおよび概要欄（説明文）の本文

上記以外のウェブサイトにはアクセスしません。閲覧履歴、Cookie、パスワード、 保存された認証情報、他のタブの内容を読み取ることはありません。

2. 端末内に保存する情報

以下を chrome.storage.local（利用者の端末内）に保存します。外部への送信はありません。

保存するもの目的
書き換える直前の概要欄の本文「取り消し」機能で元に戻すため
一度読み取った概要欄の本文再度の読み取りを省いて動作を速くするため
入力内容や設定（探す文字列など）次回起動時に復元するため

3. 保存した情報の削除

  • 読み取った概要欄：作業画面の「読み取り結果を捨てる」ボタン
  • 取り消し用の控え：作業画面の「控えを削除する」ボタン
  • すべて：Chrome から拡張機能を削除すると、保存された情報もすべて削除されます

4. 行わないこと

  • 外部サーバーへの送信、外部APIの呼び出し
  • アクセス解析、行動追跡、広告の配信
  • データの販売、第三者への提供
  • アカウント登録、ログイン、Googleアカウント連携
  • 外部から取得したコードの実行（Manifest V3 に従い、すべてパッケージに同梱）

5. 権限を使う理由

権限理由

Privacy Policy

Extension: 概要欄 一括置換 for YouTube™ Studio (Bulk Description Editor)
Last updated: August 14, 2026

This extension does not transmit any user data to external servers. All processing happens entirely within the user's browser. Neither the developer nor any third party receives any data.

1. Information Accessed

Only when the user explicitly runs an operation, this extension accesses the following on https://studio.youtube.com:

  • The list of videos on the user's own channel (video IDs and titles)
  • The title and description text of the user's own videos

It does not access any other website. It does not read browsing history, cookies, passwords, saved credentials, or the contents of other tabs.

2. Information Stored Locally

The following is stored in chrome.storage.local on the user's own device. Nothing is sent anywhere.

StoredPurpose
The description text as it was immediately before a changeTo power the Undo feature
Description text that has already been readTo avoid re-loading pages and keep previews fast
Input values and settingsTo restore them on next launch

3. Deleting Stored Information

  • Cached descriptions: the "Discard read results" button
  • Undo backup: the "Delete backup" button
  • Everything: removing the extension from Chrome deletes all stored data

4. What This Extension Does Not Do

  • Send data to external servers or call external APIs
  • Analytics, tracking, or advertising
  • Sell or share data with third parties
  • Require accounts, logins, or Google account authorization
  • Execute remotely hosted code (all code ships inside the package, per Manifest V3)

5. Why Each Permission Is Needed

PermissionReason
storageTo store the information described in section 2 on the device
scriptingTo read and edit descriptions on YouTube Studio pages
https://studio.youtube.com/*To restrict the extension to YouTube Studio only
